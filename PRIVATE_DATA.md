# Private-data policy

This repository uses the arbitrary test instance alias `vehicle-a`. Do not add a VIN, a hash/reversible derivative of a VIN, owner/dealer information, registration, adapter serial, filesystem user path, GPS, exact trip history, odometer history, or an unreviewed Health Check/session export.

Keep raw `.TSE`, J2534, CAN, screenshots/video, Techstream databases/binaries, vendor DLLs, and Ghidra projects in `../XA50-workbench` or another unversioned private location. Promote only minimal sanitized evidence and source hashes/conclusions.

ECU calibration/software IDs can be scientifically useful but form a configuration fingerprint. Tie them only to `vehicle-a` and review them before any future publication.

The complete generated Techstream atlas is local and reproducible, but ignored for the initial history because bulk redistribution rights are uncertain. The generator, profile, provenance manifest/summary, and hand-curated live evidence are the durable source of truth.
